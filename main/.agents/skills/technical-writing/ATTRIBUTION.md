# Attribution — technical-writing

**Origin**: this repository, written 2026-11-10 at the user's request to make
ASD-STE100 Simplified Technical English the core of the house language rules
for non-creative text.

**What was taken**: concepts only — one fact or instruction per sentence,
conditions before actions, active voice, one term for one concept, numbered
procedural steps, warnings before steps, and the STE sentence-length limits for
English. No text of the ASD-STE100 specification or its dictionary is copied
here; the zh-TW rules are local adaptations because STE covers English only.
